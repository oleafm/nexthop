# NextHop

A calendar-first discovery platform for nomad camps, colivings, and retreats.

## Development

```bash
npm install
npm run dev
```

The local app runs at `http://localhost:5173` by default.

## Quality checks

```bash
npm run lint
npm run build
```

The current implementation is a responsive Russian-language landing page with a
calendar preview, camp cards, product feature sections, mobile navigation,
wishlist feedback, and an email signup flow.
